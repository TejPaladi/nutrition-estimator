# Notebook Plan

The first notebooks should be lightweight, presentation-friendly examples:

1. `01_fsa_examples.ipynb`: step-by-step FSA calculation for one item.
2. `02_who_examples.ipynb`: step-by-step WHO-style calculation for one item.
3. `03_meal_level_estimation.ipynb`: MealRec+-style average of item/course scores.
4. `04_dunkin_case_study.ipynb`: run the estimator on Dunkin-style menu items.

The package code is intentionally usable before notebooks are created.
